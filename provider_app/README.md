# 이용자 앱 (Flutter)

장비 기사·업체가 쓰는 앱입니다. iOS, Android, 웹으로 빌드됩니다.

화면: 로그인 → 업체 정보·차고지·장비 등록(장비별 규격, 렉카는 견인 가능 차종) → 운영팀 승인 대기 → 출근(운행 장비 선택, 5초마다 위치 전송) → 호출 제안(15초 카운트다운, 큰 수락 버튼) → 작업 진행(길안내, 출발·도착·작업 시작·완료, 추가 요금 요청, 배정 취소) → 정산(오늘·이번 주·이번 달)

```bash
flutter pub get
flutter run --dart-define=API_URL=http://<서버 주소>:3000
flutter test
```

아직 임시인 부분: 서류 사진 제출(운영팀이 따로 받음), 앱이 꺼져 있을 때 호출을 알리는 푸시 알림, 백그라운드 위치 전송.

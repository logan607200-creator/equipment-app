# 사용자 앱 (Flutter)

장비가 필요한 사람이 쓰는 앱입니다. iOS, Android, 웹으로 빌드됩니다.

화면: 로그인(휴대폰 인증) → 홈(장비 8종) → 호출 작성(렉카: 상황·차종·목적지 / 그 외: 지금·예약, 대여 시간, 규격) → 찾는 중 → 오는 중(지도, 진행 단계, 이용자 정보) → 추가 요금 승인 → 영수증·평가, 이용 내역

```bash
flutter pub get
flutter run --dart-define=API_URL=http://<서버 주소>:3000
flutter test
```

아직 임시인 부분: 지도는 OpenStreetMap(출시 전 카카오맵·네이버지도로 교체), 전화 버튼은 안심번호 연동 전이라 꺼져 있음, 결제는 서버에서 기록만 함.
